    Provider policy

    Disable providers, endpoints, or exact model IDs. Empty reject lists add no restrictions.

    Context window variants

    Changes apply immediately and persist. Context is model metadata; refresh your client's model list. Requests use the base model upstream.

    Name stays unchanged when you edit the base model or context window. Renaming or removing it can break clients using that ID. For Codex models in Hermes, keep the codex/ prefix.

    After saving, new models receive variants only when you add them. Remove every row and save to publish no variants.
