# Native skill learning and maintenance

Source implemented; runtime activation is tracked by the owning task. The prompt
plugin now treats observations as candidates and no-op as success. It preserves
native safety and memory routing while prioritizing package-level correctness,
consolidation and total required-reading cost over accumulating text.

Ordinary learning remains proposal-only. A separately authorized native cron may
apply reviewed local SKILL.md/reference-text improvements and report verified
files and exact queue dispositions, without repeated human approval. Shared or
externally owned packages and executable/configuration changes remain excluded.
A native scripts-directory precheck suppresses empty-queue model calls. No new
mount, service, queue or parallel maintenance writers are introduced.
